# Number Guessing Game 

A simple Python project where the computer generates a random number between 1 and 100, and the user tries to guess it.

## Features
- Random number generation
- Hints for higher or lower guesses
- Tracks the number of attempts
- Handles invalid input
- Beginner-friendly Python logic

## Concepts Used
- Variables
- `random` module
- `while` loop
- Conditional statements
- Exception handling

## How to Run
1. Install Python.
2. Download `NumberGuessingGame.py`.
3. Open a terminal in the file's folder.
4. Run:

```bash
python NumberGuessingGame.py
```

## Learning Objective
To practice Python fundamentals by building an interactive guessing game.
